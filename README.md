## Homepage image

The homepage is designed to use a photo of the couple as the background image.

1. Add your photo to the `assets` folder.
2. Rename it exactly:

```text
couple-hero.jpg
```

Recommended image: high-resolution, natural light, not too busy, with enough empty/dark space for the text to remain readable.

## GitHub Pages deployment

1. Unzip this folder.
2. Upload/replace all files in your GitHub repository root.
3. Commit the changes.
4. Go to `Settings → Pages`.
5. Use `Deploy from branch`, branch `main`, folder `/root`.
6. Wait for GitHub Pages to redeploy.
